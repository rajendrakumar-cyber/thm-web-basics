1. Objective & Forensic Rationale

The objective is to perform offline forensics on HSBox3-disk001.vmdk without booting the operating system. By attaching the virtual disk image in read-only mode using guestfish, we protect volatile state, maintain hash integrity, and safely extract the root flag alongside forensic artifacts.

Cryptographic Integrity Note
Forensic disk inspection is carried out using guestfish --ro. Read-only flags ensure no disk writes or metadata updates take place, preserving the evidence hash: SHA1 = 4e468f030a3264dc7f0b4e70eaba499731e5870d.

4. Forensic Artifact Analysis

A deep-dive investigation into user history files and sensitive system configurations uncovered critical anti-forensics sanitization and database credentials:

4.1 Disk Sanitization Analysis (.bash_history)

><fs> cat /root/.bash_history apt install zerofree reboot
  • Forensic Purpose of zerofree: The utility zerofree zeroes out unallocated filesystem blocks on ext2/ext3/ext4 partitions.
  • Anti-Forensics Impact: Zero-filling unallocated disk space ensures deleted files and temporary data cannot be carved or recovered from disk slack by forensic analysts.

4.2 Database Migration & Credential Leak (.mysql_history)

><fs> cat /root/.mysql_history create database pumpkins; GRANT ALL PRIVILEGES ON pumpkins.* TO 'admin'@'localhost' IDENTIFIED BY 'admin'; grant all privilages on pumpkins.* TO 'admin'@'localhost' identified by 'admin'; show databases; use pumpkins; show tables; select * from wp_users; use pumpkins; show tables; select * from wp_user; select * from wp_users; use pumpkins select * from wp_users; show databases; drop database pumpkins; show databases; CREATE DATABASE hackerschool; GRANT ALL PRIVILEGES ON hackerschool.* TO 'admin'@'localhost' IDENTIFIED BY 'adminpass20'; FLUSH PRIVILEGES; EXIT;
  • WordPress Reconnaissance & Deletion: The operator inspected WordPress users in table wp_users under database pumpkins, then destroyed the database schema with drop database pumpkins;.
  • Active Production Database: Provisioned a new database named hackerschool.
  • Plaintext Credentials Recovered:
    • Legacy user: admin : admin
    • Active administrator: admin@localhost : adminpass20

5. Command Reference: Guestfish Forensics Cheat Sheet

Action Guestfish Command
Attach disk image in read-only mode sudo guestfish --ro -a HSBox3-disk001.vmdk
Boot appliance virtualization backend ><fs> run
Enumerate disk partitions & filesystems ><fs> list-filesystems
Mount ext4 partition to root ><fs> mount /dev/sda1 /
Inspect directory contents (Requires path) ><fs> ls /root
Display file contents (Absolute path) ><fs> cat /root/finalflag.txt
Extract evidence file to host workstation ><fs> download /etc/shadow /tmp/shadow
Terminate guestfish session ><fs> exit
